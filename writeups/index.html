Remote trust lab: five Roblox remotes that believed the client

A server script with five RemoteEvents, attacked with the same calls an exploiter would fire: client-chosen coin amounts, negative prices, a race-condition double spend and a self-granted admin rank. Four Critical, one High.

All five fixed, then re-tested against the same attacks.
